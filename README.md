# F1 Racing Pro

A fun and interactive racing game built with HTML5 Canvas and JavaScript!

## 🎮 Game Features

- **Player Car (Red)**: Control your car to race around the track
- **AI Opponents**: Compete against 2 AI-controlled cars (Blue & Yellow)
- **Nitro System**: Boost your speed by pressing Shift (limited nitro meter)
- **Physics System**: Realistic acceleration, friction, and speed mechanics
- **HUD Display**: Real-time speed and lap counter
- **Responsive Track**: Dynamic race track with lane markings

## 🕹️ Controls

| Key | Action |
|-----|--------|
| **W** or **↑** | Accelerate Forward |
| **S** or **↓** | Brake / Reverse |
| **A** or **←** | Turn Left |
| **D** or **→** | Turn Right |
| **Shift** | Nitro Boost |

## 🚀 How to Play

1. Open `index.html` in your web browser
2. Use the controls above to drive your red car
3. Avoid collisions with AI cars
4. Use nitro strategically to gain speed advantage
5. Complete laps and try to win the race!

## 📊 Game Stats

- **Your Car**: Red
- **AI Car 1**: Blue
- **AI Car 2**: Yellow
- **Max Speed**: 10 units
- **Nitro Capacity**: 100 units

## 🔧 Technical Stack

- **HTML5**: Canvas for 2D rendering
- **CSS3**: Styling and positioning
- **JavaScript (ES6)**: Game logic, physics, and input handling

## 🎯 Game Mechanics

- **Acceleration**: Build up speed gradually
- **Friction**: Naturally decelerate when not accelerating
- **Nitro System**: Temporary speed boost with cooldown
- **AI Movement**: Semi-autonomous AI cars with basic pathfinding
- **Collision Physics**: Car positions updated based on speed and angle
